# 当確!2

衆議院選挙の新人候補として政界に入り、当選を重ねて総理をめざすブラウザゲームです。
前作「当確!」をもとに、ゼロから作り直している2作目です。

- **当確!2(このフォルダの `index.html`)**:選挙区の選挙戦から、議員の任期、出世、党首選、全国の総選挙、連立と政権運営まで。新人候補から総理までを通して遊べます。
- **前作「当確!」(`legacy/index.html`)**:議員任期・党首・政権運営・対戦モード・史実シナリオまでそろった、これまでの版です。タイトルの「前作で遊ぶ」からも開けます。

## 遊び方

`index.html` をブラウザで開くだけで遊べます(ビルドやインストールは不要)。セーブはブラウザの localStorage に残ります。

公開している版:https://yoshirieru.github.io/tokaku-game/ (当確!2 を main に入れるまでは前作です)

## 当確!2 の内容

- 地図が主役の1画面。PCでもスマホでも、縦にスクロールせずに遊べます。
- 立候補する選挙区を6つから選べます。都会・保守王国・工業都市・改革の地盤など、地図も相手も党の強さもちがいます。
- 毎朝配られる5枚の手札から、体力3のぶんだけカードを選び、地区に出して支持を伸ばします。
- カードを選ぶと、どの地区で何ポイント伸びるかが地図に出ます。出た数字がそのまま効きます。
- 相手は朝に「今日どこに入るか」を予告します。先回りして止めるか、固い票で受け止めるかを選べます。
- 「約束」のカードは強力ですが、背負った約束は当選したあともついてきます。
- 8日間の選挙戦のあと、開票特番で30分ごとに票が開いていきます。
- 当選すると議員の任期です。国会で約束を果たし、地元の地盤を固め、党のために働きます。解散の見込みは画面に出ます。
- 果たした約束は次の選挙で「推薦」のカードに、手をつけなかった約束は「破った約束」のカードになって返ってきます。
- 小選挙区で負けても、惜敗率が高ければ比例代表で復活できます。結果は開票のあと、午前1時30分に分かります。
- 落選しても、浪人として地元を回り、次の選挙で返り咲きをめざせます。続けて3回議席を得られないと、党の公認を失います。
- 当選を重ね、党のために働くと、政務官・副大臣・大臣・党三役へと出世します。
- 党三役まで上がると党首選に立てます。党首になると、選挙は全国11ブロック・465議席の総選挙になり、開票特番で議席が積み上がります。
- 総選挙でどの党も過半数に届かなければ、誰と組むかを選びます。大臣ポストや相手の公約の受け入れが、連立の条件になります。
- 首相になると、内閣支持率を保ちながら公約を果たし、好きなときに衆議院を解散できます。連立相手を怒らせると内閣が倒れ、支持率が低いままだと退陣に追い込まれます。
- 立候補の準備の画面から、はじめから党首として総選挙を戦う近道もあります。
- いつでも引退でき、政治家としての歩みに S〜D の評価がつきます。
- 政界を去るたびに「殿堂」に記録が残り、実績(18個)が集まります。セーブデータとは別に残ります。
- 「2人で対戦」:1台の画面で2人が交互に操作し、同じ選挙区で票を競います(3人目の候補はコンピューター)。
- 政治とカネ:資金を集めるたびに、収支報告書に正直に載せるかを選びます。載せないお金は使えますが、記者・元秘書・検察に追われ、発覚すれば炎上、公認取り消し、議員辞職まであります。
- 選挙違反:買収の誘いや怪文書、開票所の不審な動き(立会人を送れば防げる)。陣営が有罪になると連座制で当選無効になり、選挙区を移ります。北津1区で特に起きやすい。
- 接戦が続くと有権者の関心が高まり、投票率が大きく上がります。
- 当選2回からは、党を割って新党を作れます(党の名前・略称・色は自分で決められます)。元の党の刺客との4人の争いを勝ち抜き、議席を積めば、ほかの党から合流の誘いが来ます。
- 「史実シナリオ」では、実際にあった総選挙(1993・2005・2009・2012年)の局面を、実在の党の党首として戦えます(このモードだけ実名。議席は主な3党の争いに置きかえた目安です)。
- 5〜6回に1回の選挙では「奔流」が起きます。だれも本気にしていなかった候補に眠っていた票が流れ込み、投票率は8割を超えます。世論調査には映らない票が開票の後半に一気に開き、出ていた当確が取り消されることもあります。
- 毎年の予算編成で、すぐの支持と、数十年かけて国に出る効き目をはかりにかけます。政界を去ると、30年後の新聞「未来日報」が飛んできて、あなたの時代が国をどう変えたかを報じます。
- 参議院:3年ごとに参院選があります。党の候補を応援して議席を伸ばせば次の衆院選に勢いがつき、首相の与党が過半数を割ると「ねじれ国会」で重要法案が進みにくくなります。
- 区割り改定:一票の格差の判決で、選挙区が隣と合わさったり、なくなったりします。同じ党の現職と公認を争うことも。
- カードはダブルクリックですぐ使えます。使ったカードは、その日のうちなら「取り消す」(Ctrl+Z)で戻せます。

登場する政党・政治家・選挙区はすべて架空です。
