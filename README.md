# 当確!(国政キャンペーン&政権ゲーム)

衆議院選挙の新人候補として政界に入り、再選を重ねて党首になり、総選挙を戦って政権を取り、守るブラウザゲームです。

## 遊び方

**ブラウザで遊ぶ:https://yoshirieru.github.io/tokaku-game/**

手元で遊ぶときは、`index.html` をブラウザで開くだけで遊べます(ビルドやインストールは不要)。セーブはブラウザの localStorage に残ります。

## 内容

- 選挙区の選挙戦(5つの選挙区から選べる)、開票特番、比例復活
- 議員任期・出世・党内の派閥・党首選
- 党首として全国の総選挙、連立交渉、政権運営、経済の指標
- 新党の結成(参院選の比例から挑むこともできる)、補欠選挙・地方選挙
- SNSと炎上、国会論戦のカードバトル、2人の対戦モード
- エンディングとレガシー評価、殿堂・実績

登場する政党・政治家・選挙区はすべて架空です。宗教団体と、その団体が支持母体の政党(公明党、幸福実現党)だけは実名で、公開されている事実だけで描いています。

仕様と開発の記録は [CLAUDE.md](CLAUDE.md) にあります。バランス確認用の自動プレイは `node tools/autoplay.js` で動きます。
